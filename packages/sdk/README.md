# @bluecallio/sdk

Official JavaScript and TypeScript SDK for BlueCallio, a developer-focused real-time communication infrastructure platform for audio, video, screen sharing and WebRTC applications.

The SDK provides:

- REST API client
- Call creation and management
- Participant session handling
- Call acceptance and rejection
- Call joining and leaving
- Call termination
- Call details and call listing
- Headless WebRTC meeting engine
- TypeScript type definitions

## Installation

```bash
npm install @bluecallio/sdk
```

---

## Requirements

- Node.js 18+
- JavaScript or TypeScript
- A BlueCallio project
- A BlueCallio API key

---

## Security

The `BlueCallioClient` uses your BlueCallio API key to authenticate requests.

**Never expose your API key in frontend or browser code.**

Use `BlueCallioClient` from:

- Node.js servers
- Backend applications
- API routes
- Serverless functions
- Other trusted server-side environments

For browser applications, use the session information generated by your backend and use the BlueCallio meeting functionality or `@bluecallio/react`.

# REST Client

The `BlueCallioClient` provides access to the BlueCallio REST API.

## Create a Client

### CommonJS

```js
const { BlueCallioClient } = require("@bluecallio/sdk");

const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY
});
```

### ES Modules

```js
import { BlueCallioClient } from "@bluecallio/sdk";

const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY
});
```

### TypeScript

```ts
import { BlueCallioClient } from "@bluecallio/sdk";

const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY
});
```

# Configuration

The client accepts the following configuration:

```ts
interface BlueCallioConfig {
  apiKey: string;
  baseUrl?: string;
}
```

### `apiKey`

Your BlueCallio project API key.

This value is required.

```ts
const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY!
});
```

### `baseUrl`

Optional API base URL.

If omitted, the SDK currently uses:

```text
https://api.bluecallio.com
```

You can provide your own API base URL:

```ts
const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY!,
  baseUrl: "https://api.bluecallio.com"
});
```

For a custom/self-hosted BlueCallio deployment:

```ts
const client = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY!,
  baseUrl: "https://your-domain.com/api"
});
```

# Create a Call

Create a new audio or video call.

```ts
const result = await client.createCall({
  callerId: "user-1",
  receiverId: "user-2",
  type: "VIDEO"
});
```

The supported call types are:

```ts
type CallType = "AUDIO" | "VIDEO";
```

### Audio Call

```ts
const result = await client.createCall({
  callerId: "user-1",
  receiverId: "user-2",
  type: "AUDIO"
});
```

### Video Call

```ts
const result = await client.createCall({
  callerId: "user-1",
  receiverId: "user-2",
  type: "VIDEO"
});
```

If `type` is not provided, the SDK uses:

```text
VIDEO
```

### Response

The create-call response contains call and participant information, including hosted URLs and participant session tokens.

```ts
const result = await client.createCall({
  callerId: "user-1",
  receiverId: "user-2",
  type: "VIDEO"
});

console.log(result.callId);
console.log(result.hostedUrl);
console.log(result.participants);
```

The participant information includes values such as:

```text
participantId
token
hostedUrl
expiresAt
```

# Join a Call

Record a participant joining a call.

The participant session token is required.

```ts
const result = await client.joinCall(
  callId,
  participantToken
);
```

Example:

```ts
const result = await client.joinCall(
  "call_123",
  "participant_session_token"
);

console.log(result);
```

The SDK sends the participant token using:

```http
Authorization: Bearer <token>
```

The API key is not used as the participant session token.

---

# Leave a Call

Record that a participant has left a call.

```ts
const result = await client.leaveCall(
  callId,
  participantToken
);

console.log(result.left);
```

Example:

```ts
const result = await client.leaveCall(
  "call_123",
  "participant_session_token"
);

if (result.left) {
  console.log("Participant left the call");
}
```

---

# Accept a Call

Accept a pending call.

```ts
const call = await client.acceptCall(
  callId,
  participantToken
);
```

The participant token is optional:

```ts
const call = await client.acceptCall("call_123");
```

If a token is provided, it is sent as:

```http
Authorization: Bearer <token>
```

---

# Reject a Call

Reject a pending call.

```ts
const call = await client.rejectCall(
  callId,
  participantToken
);
```

The token is optional:

```ts
const call = await client.rejectCall("call_123");
```

---

# End a Call

End an active call.

```ts
const call = await client.endCall(
  callId,
  participantToken
);
```

The token is optional:

```ts
const call = await client.endCall("call_123");
```

# Get a Call

Retrieve information about a specific call.

```ts
const call = await client.getCall("call_123");

console.log(call);
```

Method signature:

```ts
getCall(callId: string): Promise<Call>
```

---

# Get Call Details

Retrieve authenticated call details using a participant session token.

```ts
const details = await client.getCallDetails(
  "call_123",
  "participant_session_token"
);

console.log(details);
```

Method signature:

```ts
getCallDetails(
  callId: string,
  token: string
): Promise<CallDetails>
```

Call details can include:

- Call information
- Branding information
- Participant information
- Participant session token information

---

# List Calls

Retrieve all calls associated with the current project.

```ts
const calls = await client.getCalls();

console.log(calls);
```

Method signature:

```ts
getCalls(): Promise<Call[]>
```

Example:

```ts
const calls = await client.getCalls();

for (const call of calls) {
  console.log(call);
}
```

# Headless WebRTC Meeting

The SDK also exports `BlueCallioMeeting`.

```ts
import { BlueCallioMeeting } from "@bluecallio/sdk";
```

`BlueCallioMeeting` provides the headless meeting/WebRTC functionality that can be used when you want to build your own communication interface.

This allows you to use BlueCallio's communication engine while keeping control over your application's UI.

For React applications, the higher-level React package is available:

```bash
npm install @bluecallio/react
```

# Server-Side Example

A typical backend integration looks like this:

```ts
import { BlueCallioClient } from "@bluecallio/sdk";

const bluecallio = new BlueCallioClient({
  apiKey: process.env.BLUECALLIO_API_KEY!
});

async function createVideoCall() {
  const call = await bluecallio.createCall({
    callerId: "user-1",
    receiverId: "user-2",
    type: "VIDEO"
  });

  return call;
}
```

Your frontend can then use the call/session information returned by your backend.

# Recommended Application Architecture

A typical BlueCallio application can follow this architecture:

```text
                    Your Application
                           │
             ┌─────────────┴─────────────┐
             │                           │
             ▼                           ▼
        Your Backend              Your Frontend
             │                           │
             │ @bluecallio/sdk           │
             ▼                           │
       BlueCallio API                   │
             │                           │
             ▼                           ▼
      Call + Session Info       @bluecallio/react
                                         │
                                         ▼
                                  WebRTC Meeting
```

The important security rule is:

```text
API key
   │
   ▼
Backend only
```

Never send the project API key to the browser.

# Error Handling

SDK API requests throw an `Error` when the BlueCallio API responds with a non-success status.

Use normal `try/catch` handling:

```ts
try {
  const call = await bluecallio.createCall({
    callerId: "user-1",
    receiverId: "user-2",
    type: "VIDEO"
  });

  console.log(call);
} catch (error) {
  console.error("BlueCallio request failed:", error);
}
```
